Better X Likes 개인정보처리방침

2026-10-13 · Version 1.6.0 · Junhak Kim

1. 개요

Better X Likes는 X 목록을 그리드로 표시하고 선택적으로 게시물 팝업과 X 번역을 제공합니다. X Corp.의 공식 제품이 아닌 독립 확장 프로그램입니다. 개발자 서버, 분석 도구, 광고는 없습니다.

2. 처리하는 정보

현재 X 페이지의 경로·검색 매개변수, 게시물 요소·링크·ID, 크기, 영상 재생 입력을 화면 배치와 재생 제어를 위해 페이지 메모리에서 처리합니다. 팝업에서는 선택한 게시물의 본문·작성자·이미지·영상·인용을 읽습니다. 답글은 요청하지 않습니다. 번역 보기 버튼을 누를 때만 번역을 요청합니다.

3. 로그인 세션과 통신

페이지 스크립트는 X 자체의 동일 출처 조회 요청에서 authorization, CSRF, 언어 헤더를 확인합니다. 이 값은 현재 페이지 메모리에만 유지하며 선택한 게시물과 번역의 동일 출처 X GET 요청에만 재사용합니다. 확장 프로그램 저장소, 개발자 또는 별도 서버로 전달하지 않습니다. 비밀번호를 요구하거나 인증 쿠키를 직접 읽지 않습니다. X가 연결한 abs.twimg.com 공개 스크립트에서 인증 헤더·자격 증명 없이 조회 메타데이터만 읽고, 내려받은 코드를 실행하지 않습니다. 미디어는 X의 미디어 호스트에서 불러옵니다. 해당 요청의 X 측 처리는 X 개인정보처리방침을 따릅니다.

4. 설정과 권한

chrome.storage.local에는 enabled, pageModes, tweetPopup 설정만 저장합니다. storage 권한은 이 설정에 사용합니다. 콘텐츠 스크립트는 x.com과 twitter.com에서만 실행하며 방문 기록 API는 사용하지 않습니다. Chrome 언어로 번들에 포함된 한국어·영어·일본어 UI를 선택합니다. X 번역에는 X 세션의 언어 설정을 사용합니다.

5. 보관과 제한된 사용

게시물, 번역, ID, 인증 헤더는 영구 저장하지 않습니다. 팝업을 닫으면 내용이 제거되며 X 탭을 닫거나 새로고침하면 페이지 메모리가 해제됩니다. 확장 프로그램을 제거하면 저장된 설정도 제거됩니다. 사용자 데이터를 판매하거나 광고·신용평가·대출 판단에 사용하지 않습니다. 처리는 사용자에게 보이는 그리드·팝업·번역·영상 기능으로 한정하며 Chrome 웹 스토어 Limited Use 요구사항을 준수합니다.
