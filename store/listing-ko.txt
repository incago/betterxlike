짧은 설명 (manifest.json에 포함)
X의 홈·검색·프로필·북마크·마음에 들어요를 1~4열 그리드로 표시하고, 화면별로 기본 목록을 선택할 수 있습니다.

상세 설명 (이 아래 본문을 대시보드에 복사)

X(트위터)의 게시물을 홈·검색·프로필·북마크·마음에 들어요에서 한눈에 살펴보세요.
Better X Likes는 긴 세로 목록을 창 크기에 맞는 그리드로 바꾸는 Chrome 확장 프로그램입니다.

• 프로필 상단을 전체 폭으로 표시하고 배너 높이는 최대 200px, 프로필 사진은 최대 145px로 유지합니다. 배너 이미지는 중앙 기준으로 잘라 채웁니다.
• 그리드에서는 게시물 사이의 팔로우 추천을 숨겨 게시물과 겹치지 않게 합니다. 기본 목록으로 전환하면 다시 표시합니다.
• 넓은 창에서는 한 줄에 최대 4개의 게시물을 표시합니다.
• 창을 줄이면 3열, 2열, 아주 좁은 화면에서는 1열로 자동 전환합니다.
• 그리드를 선택한 화면에서 우측 검색·트렌드·팔로우 추천 영역을 숨겨 콘텐츠 공간을 넓힙니다.
• 그리드의 영상 자동재생을 차단하고, 직접 재생 버튼을 누른 영상만 재생을 허용합니다.
• 팝업에서 화면별로 그리드와 기본 목록을 선택할 수 있습니다. 전체 스위치로 모든 화면을 끌 수도 있습니다.
• 처음 설치하면 북마크·마음에 들어요만 그리드로, 홈·검색·프로필은 기본 목록으로 시작합니다. 기존에 저장한 선택은 유지됩니다.
• X의 라이트/다크 모드 색상을 사용합니다.
• 팝업은 Chrome의 인터페이스 언어에 따라 한국어·영어·일본어로 표시하며, 그 외 언어에서는 영어를 사용합니다.

사용 방법
1. 설치한 뒤 이미 열려 있는 X 탭을 새로고침하세요.
2. X에 로그인하고 홈·검색·프로필·북마크·마음에 들어요를 여세요.
3. 원하는 너비로 창 크기를 조절하세요. 팝업에서 각 화면의 보기 방식을 선택하세요.

개인정보와 권한
전체 그리드 켜기/끄기와 화면별 보기 설정만 브라우저에 저장합니다. 페이지 주소, 게시물 요소·링크와 영상 재생 입력은 화면 배치와 재생 제어를 위해 기기 안에서만 처리합니다. 게시물이나 방문 기록을 별도 파일이나 서버에 저장하지 않으며, 개발자에게 전송하지 않습니다. 광고, 분석 도구, 원격 실행 코드가 없습니다.

X 로그인이 필요하며, 확장 프로그램에 별도 계정을 만들거나 로그인 정보를 입력할 필요는 없습니다. X의 화면 구조가 변경되면 일부 기능에 조정이 필요할 수 있습니다. 문제가 있으면 그리드를 끄고 X 탭을 새로고침하세요.
