Short description
View X home, search, profiles, bookmarks and likes in a 1–4 column grid, with a default layout option for each page.

Detailed description

Browse posts on X (Twitter) at a glance: home, search results, profiles, bookmarks and likes.
Better X Likes turns long vertical timelines into grids that fit your browser window.

• Enable Open tweets in a popup to read full text, images, video and quoted posts above the grid without losing your scroll position or automatically opening another tab.
• Translate posts using X inside the popup, then switch back to the original. Use Open in X for replies.
• Use the full profile header width while capping banner height at 200px and portraits at 145px. Banner images are cropped around their center to fill the width.
• Hide inline follow suggestions in grids to keep posts aligned. Switching to Default list restores the suggestions.
• See up to four posts per row in a wide window.
• Automatically switch to three, two or one column as the window gets narrower.
• Hide the right search, trends and suggested follows sidebar on pages set to Grid, giving posts more room.
• Stop automatic video playback in grids. Play a video by clicking its player control or using the keyboard.
• Choose Grid or Default list separately for each page in the extension popup. A master switch can disable all grids while keeping your choices.
• New installations use grids for bookmarks and likes; home, search and profiles start with the default list. Saved choices are preserved.
• Use X’s existing light or dark theme.
• Use the popup in Korean, English or Japanese. Its language follows Chrome’s interface language; other languages fall back to English.

How to use
1. After installing or updating, reload any X tabs that are already open.
2. Sign in to X and open home, search results, a profile, bookmarks or likes.
3. Resize the window and choose a layout for each page in the popup.

The profile preference applies to your profile and other profiles. Post details, messages, notifications, Explore, follower lists and pages without a tweet timeline keep X’s default layout.

Privacy and permissions
Grid and popup preferences are saved locally. Selected posts and translations are requested directly from X using the current page session. Session headers stay in page memory and are never stored by the extension or sent to the developer. Public X scripts are read only for query definitions; downloaded code is not executed.

You need to sign in to X, but the extension requires no separate account or login credentials. Changes to X’s page structure may require updates to this extension. If something stops working, turn off the grid and reload the X tab.
