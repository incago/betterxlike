Better X Likes Privacy Policy

2026-10-13 · Version 1.6.0 · Junhak Kim

1. Overview

Better X Likes arranges X timelines into a grid and offers an optional post popup with X translation. It is an independent extension, not an official X Corp. product. There is no developer backend, analytics or advertising.

2. Information processed

The current X page path/query, rendered posts, links/IDs, dimensions and video gestures are processed in page memory for layout and playback. The optional popup reads the selected post, author, images, videos and quoted post. Replies are not requested. Translation is requested only when the user clicks Translate post.

3. Session authentication and requests

The page script observes headers from X’s own same-origin read requests, including authorization, CSRF and interface-language headers. They stay in that page’s memory and are reused only for same-origin X GET requests for the selected post and its translation. They are never sent to extension storage, the developer or a separate server. The extension does not ask for passwords or read authentication cookies directly. Public query metadata is fetched from the X-linked abs.twimg.com main script without session headers or credentials; downloaded code is not executed. Post media loads from X media hosts. X processes these requests under its own privacy policy.

4. Saved settings and permissions

Only enabled, pageModes and tweetPopup preferences are saved in chrome.storage.local. The storage permission supports those settings. Content scripts run only on x.com and twitter.com; no browsing-history API is used. Chrome’s UI language selects bundled English, Korean or Japanese messages. X’s session language is used for X translation.

5. Retention and limited use

Posts, translations, IDs and authentication headers are not persistently saved. Closing a popup removes its content; closing or reloading the X tab clears page memory. Removing the extension removes its saved settings. We do not sell user data or use it for advertising, creditworthiness or lending. Processing is limited to the user-visible grid, popup, translation and video features in accordance with Chrome Web Store Limited Use requirements.
