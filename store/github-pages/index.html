Better X Likes 개인정보처리방침

게시자: Junhak Kim
최종 업데이트: 2026년 10월 7일
문의: incago@gmail.com

Better X Likes는 X의 게시물 목록을 그리드로 표시합니다. 1.4.1까지는 북마크·마음에 들어요를, 1.5.0부터는 홈·검색 결과·프로필 게시물 목록도 지원하며 화면별로 기본 목록을 선택할 수 있습니다. 1.5.1에서는 한국어·영어 인터페이스 지원을, 1.5.2에서는 일본어 지원을 추가했습니다. 화면 배치와 영상 제어에 필요한 정보는 사용자의 브라우저 안에서 처리하며, 확장 프로그램이 개발자나 제3자 서버로 전송하지 않습니다.

1. 기기 안에서 처리하는 정보

적용할 페이지를 판단하기 위해 현재 열린 x.com 또는 twitter.com 페이지의 주소 경로와 검색 매개변수를 확인합니다. 게시물 배치를 위해 화면에 표시된 게시물 요소, 게시물 링크와 ID, 카드의 크기와 순서를 일시적으로 메모리에서 처리합니다. 영상 자동재생을 막고 직접 요청한 재생만 허용하기 위해 영상 요소와 해당 플레이어의 클릭·Enter/Space 입력을 처리합니다.

이 정보로 별도의 방문 기록이나 게시물 보관함을 만들지 않습니다. 게시물 데이터와 재생 입력은 확장 프로그램 저장소에 기록하지 않으며, 개발자가 받아 보거나 열람하지 않습니다. 입력한 키보드 텍스트를 기록하지 않습니다.

한국어·영어·일본어 인터페이스를 선택하기 위해 Chrome의 인터페이스 언어를 기기 안에서 사용합니다. 그 외 언어에서는 영어를 표시합니다. 별도의 언어 설정을 저장하거나 전송하지 않습니다.

2. 저장하는 설정

그리드 전체 켜기/끄기(enabled)와 1.5.0부터 제공하는 화면별 보기 설정(pageModes)을 chrome.storage.local에 저장합니다. 설정은 같은 브라우저에서 기능 상태를 유지하고 열린 X 탭에 설정 변경을 적용하는 데 사용합니다. 확장 프로그램은 설정을 자체 서버에 동기화하지 않습니다.

3. 권한과 적용 범위

storage 권한은 위 설정 저장에 사용합니다. 콘텐츠 스크립트는 x.com과 twitter.com에서 페이지 이동을 감지하며, 화면 변경은 지원하는 게시물 목록에서 해당 화면의 그리드 설정이 켜져 있을 때 적용합니다. 기본 목록을 선택하거나 전체 스위치를 끄면 X의 원래 레이아웃과 영상 재생 동작을 사용합니다. 다른 사이트에 접근하지 않고 Chrome의 전체 방문 기록 API를 사용하지 않습니다.

4. 전송·공유 및 제한된 사용

확장 프로그램에는 사용자 데이터를 외부로 보내는 요청, 광고 SDK, 분석 도구 또는 추적 코드가 없습니다. 사용자 데이터를 판매하거나 제3자에게 전달하지 않으며, 광고·신용평가·대출 판단에 사용하지 않습니다. 정보 처리는 사용자가 볼 수 있는 게시물 그리드와 영상 재생 제어 기능으로 한정하며, Chrome 웹 스토어 사용자 데이터 정책의 Limited Use 요구사항을 준수합니다.

X가 로그인, 게시물 표시, 영상 스트리밍을 위해 하는 통신은 X 서비스 자체의 동작입니다. 확장 프로그램은 X 로그인 정보나 인증 쿠키를 요구하지 않습니다. X의 개인정보 처리는 X의 정책에 따릅니다.

5. 보관과 삭제

카드 ID·크기·재생 제어 상태는 해당 페이지의 메모리에서만 처리하며 영구 저장하지 않습니다. 탭을 닫거나 문서를 새로고침하면 이 상태가 해제됩니다. 저장된 전체 켜기/끄기와 화면별 보기 설정은 팝업에서 바꿀 수 있으며, 확장 프로그램을 제거하면 확장 프로그램의 로컬 저장소도 제거됩니다. X 계정의 북마크나 마음에 들어요는 X에서 관리하며 확장 프로그램을 제거해도 삭제하지 않습니다.
