# Better X Likes

[한국어](README.md) | [English](README.en.md) | 日本語

Xの**ホーム・検索結果・プロフィール・ブックマーク・いいね**を、ウィンドウの幅に応じて**1行に1〜4件のポスト**を表示するグリッドに変えるChrome拡張機能です。ポップアップで画面ごとに**グリッド / 標準の一覧**を選べます。グリッド表示では右側の検索・トレンド・おすすめユーザーを非表示にし、左側のナビゲーションは保持します。

1.5.2では、日本語・韓国語・英語に対応しています。表示言語はChromeのインターフェース言語に従い、それ以外の言語では英語を表示します。言語が変わっても既存の表示設定は保持されます。X自体の画面やポストの内容を翻訳する機能ではありません。

## ローカルでのインストール・更新

1. [v1.5.10のインストール用ZIPをダウンロード](https://github.com/incago/betterxlike/releases/download/v1.5.10/better-x-likes-1.5.10.zip)し、展開します。変更内容は[リリースページ](https://github.com/incago/betterxlike/releases/tag/v1.5.10)で確認できます。
2. Chromeで `chrome://extensions` を開きます。
3. **デベロッパー モード**をオンにします。
4. **パッケージ化されていない拡張機能を読み込む**から、展開したフォルダー（`manifest.json` があるフォルダー）を選びます。
5. **開いているXのタブも再読み込みします。** ページ起動時に登録される動画制御コードを更新するために必要です。
6. 通常の方法でXにログインし、対応するページを開きます。

すでにローカルでインストールしている場合は、インストール先のファイルを新しいバージョンに置き換え、`chrome://extensions`で拡張機能の**再読み込み**ボタンを押してから、開いているXのタブも再読み込みします。

ツールバーに固定すると、ポップアップを開きやすくなります。**グリッドを使う**全体スイッチをオフにすると、画面ごとの選択を保持したまま、すべてのグリッドを無効にできます。設定は同じブラウザにローカル保存され、開いているXのタブにも適用されます。

1.5.4から、新規インストール時や保存された画面設定がない場合は、**ブックマーク・いいねだけグリッド**、**ホーム・検索・プロフィールは標準の一覧**で開始します。保存済みの選択は更新後も保持します。初期設定、保存設定の保持、グリッドへの切り替えを含む自動テスト59件に合格しました。

## 対応する画面と動作

- ホーム: `/home`
- ポストを含む検索結果: `/search`
- プロフィール: `/username`、`/username/with_replies`、`/username/media`、`/username/highlights`。自分と他のユーザーに同じ設定を適用します。
- ブックマーク: `/i/history`、`/i/bookmarks`
- いいね: `/i/history/likes`

ポストの詳細、メッセージ、通知、話題を検索、フォロワー一覧、ポストのタイムラインがない画面は、Xの標準表示を使います。**標準の一覧**を選ぶと、その画面のレイアウト、右サイドバー、動画再生の動作がXの標準に戻ります。

利用できるコンテンツ領域が1060px以上なら4列、800〜1059pxなら3列、540〜799pxなら2列、540px未満なら1列です。ウィンドウの幅を変えると自動で配置を更新します。

ポストを複製せず、Xが表示した既存の要素にスタイルを適用します。リンク、ボタン、メディアの操作、X自身による文章の省略は保持されます。仮想スクロールと追加読み込みはXが管理し、拡張機能は測定用のセルの高さとセル内のカード位置を調整します。

グリッド内の動画は、該当プレーヤーの操作ボタンをクリックするかキーボードで操作するまで停止した状態になります。ポスト本文や「いいね」のクリックは再生要求として扱いません。ページのMAIN実行環境で、要求されていない `play()` を再生開始前に拒否し、再生・停止を繰り返す現象を防ぎます。標準表示に切り替えるか対象画面から移動すると、通常の動画動作に戻ります。

## 権限とプライバシー

`storage` 権限は、全体スイッチ `enabled` と5画面の表示設定 `pageModes` だけを `chrome.storage.local` に保存するために使います。コンテンツスクリプトは `x.com` と `twitter.com` で画面遷移と対応するタイムラインを検出します。現在のパス・クエリ、表示中のポストのリンク・ID、サイズ、プレーヤーへの操作はページのメモリで一時的に処理します。ポスト、閲覧履歴、再生操作を保存したり、開発者へ送ったりしません。独自のサーバー、アクセス解析、外部の実行コードはありません。

## 開発と検証

```sh
npm ci
npm test
npm run preview
```

ブラウザの自動検証は、初回に `npx playwright install chromium` を実行し、その後 `npm run test:browser` で実行できます。DOMとブラウザの両方を検証するには `npm run test:all`、インストール済みChromeを使うには `PLAYWRIGHT_CHANNEL=chrome npm run test:browser` を実行します。テストサーバーは `127.0.0.1:4175` を使用します。GitHub Actionsでも両方を実行します。1〜4列、仮想スクロールと再表示、メディアの高さ変更、ホーム更新、プロフィール写真の外枠、おすすめユーザー、実際の動画再生と失敗、3言語の設定保存を検証します。

途中にポストを追加すると、画面外のポストも含めて順番を調整します。通常の配置更新は変更された行だけを再計算し、列数や順番が変わる場合はキャッシュ全体を再計算します。動画再生が失敗すると手動再生の許可を解除し、新しい再生要求の成功は維持します。

`http://127.0.0.1:4173` のプレビューは合成ポストを使い、Xのアカウントには接続しません。`/home`、`/search?q=cookie`、`/incago`、`/i/history`、`/i/history/likes` を確認できます。

`?virtual=1`（別のクエリがあれば `&virtual=1`）を付けると、最初の7件から6ページ・42件までの自動読み込みと、画面外のDOM要素の削除を再現します。プレビュー内のブラウザテストでは、配置、遅れて変わるメディアの高さ、元のイベント処理、標準表示への復元を確認します。

`?videos=1` は、Canvasストリームから生成した実際のブラウザ動画で、自動再生の再試行、手動再生、標準動作への復元を確認します。外部動画はダウンロードしません。ポップアップのプレビューは `/popup.html?lang=ja`、`?lang=ko`、`?lang=en` で確認でき、Chrome APIを模擬したローカル設定を使います。

1.5.1では自動テスト54件に合格しました。1.5.2では日本語のラベル、状態・エラーメッセージ、件数、設定保持も検証し、自動テスト56件に合格しました。ローカルの検証は、現在のXにログインした状態での確認に代わるものではありません。XのDOMや測定方法は変わることがあります。問題があればグリッドをオフにし、Xのタブを再読み込みしてください。
