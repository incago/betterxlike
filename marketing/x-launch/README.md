# Better X Likes — GitHub 사전 공개 소개 자료

Chrome 웹 스토어 등록 전에 GitHub 저장소와 함께 소개하는 게시글 초안입니다. 좋아요로 저장한 트윗을 긴 세로 목록에서 다시 보기 불편해 만들었다는 계기를 중심으로 작성했습니다.

## 추천 게시 방법

첫 게시글에는 `post-ko.txt`를 붙이고 `01-launch.png`, `02-before-after.png`를 순서대로 첨부합니다. 창 크기에 따른 보기까지 보여주려면 `03-responsive.png`를 세 번째로 첨부합니다. 세 이미지 모두 1600×1000 PNG입니다.

GitHub 주소는 https://github.com/incago/betterxlike 로 이미 들어 있습니다. 스토어 설치 링크를 기다리거나 교체할 필요가 없습니다. 모든 이미지에도 저장소 주소와 사전 공개 표기를 넣었습니다.

`reply-ko.txt`는 저장소의 현재 기능과 수동 설치 안내, 피드백 요청을 덧붙이는 답글입니다. 첫 게시글은 만든 계기와 핵심 기능을 중심으로, 자세한 기능은 답글로 나눴습니다.

`story-ko.md`는 글자 수 제한 없이 소개할 때 쓰는 긴 설명입니다. `post-en.txt`와 `post-ja.txt`는 영어·일본어 게시글용 번역이고, 이미지 문구는 한국어입니다. 이미지의 접근성 설명은 `alt-text-ko.txt`에 있습니다.

소개글에 다른 제품의 향수나 스토어에서 설치할 수 있다는 표현을 사용하지 않았습니다. 이 자료를 만들면서 X에 게시하거나 예약하지 않았습니다.

## 소개하는 기능과 설치

GitHub의 1.5.9 소스를 기준으로 작성했습니다. 핵심은 북마크·마음에 들어요의 1~4열 반응형 그리드입니다. 두 화면은 처음 설치 시 기본으로 그리드가 켜집니다. 홈·검색·프로필은 팝업에서 원하는 화면만 선택할 수 있습니다. 영상은 직접 재생하고 그리드에서는 우측 사이드바를 숨깁니다.

현재 수동 설치 방법은 저장소 README에 있습니다. 저장소를 다운로드 또는 복제하고, Chrome의 `chrome://extensions`에서 개발자 모드를 켠 뒤 압축 해제된 확장 프로그램으로 프로젝트 폴더를 불러옵니다. 자세한 단계는 저장소 안내를 따릅니다.

실제 Chrome 웹 스토어 제출 상태나 등록정보는 변경하지 않았습니다.

## 화면 출처

개인 계정이나 저장된 게시물을 촬영하지 않았습니다. `demo.html`의 창작 샘플 게시물에 현재 저장소의 실제 확장 CSS/JS를 적용하고 브라우저로 촬영했습니다. 기본 보기와 그리드 비교는 같은 게시물을 사용합니다. 각 이미지에 데모 표기를 넣었습니다. 4열·2열·1열은 실제 렌더링 결과로 확인했습니다.

`grid.png`, `native.png`, `two-columns.png`, `one-column.png`는 합성 전 원본 화면 캡처입니다. `index.html`은 소개 이미지의 편집 가능한 HTML 원본입니다.

## 재생성

저장소 루트에서 `node marketing/x-launch/preview.cjs`를 실행합니다.

- 그리드: `http://127.0.0.1:4174/i/history/likes?width=1320`
- 기본 목록: `http://127.0.0.1:4174/i/history/likes?mode=native&width=990`
- 2열: `http://127.0.0.1:4174/i/history/likes?width=788`
- 1열: `http://127.0.0.1:4174/i/history/likes?width=488`
- 대표 이미지: `http://127.0.0.1:4174/marketing/x-launch/index.html?slide=hero`
- 비교 이미지: 위 URL의 `slide=comparison`
- 반응형 이미지: 위 URL의 `slide=responsive`

각 데모의 창 너비를 맞춰 촬영합니다. 소개용 HTML 출력 크기는 1600×1000입니다.

짧은 게시글은 URL을 23자로 계산하고 한글·일본어의 가중치를 반영해 일반 게시글 길이 안에 맞췄습니다. [X 공식 문자 수 안내](https://docs.x.com/fundamentals/counting-characters)를 참고했습니다. 문구를 추가하면 게시창에서 다시 확인합니다.
