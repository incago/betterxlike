# Better X Likes — X 출시 소개 자료

실제로 스토어에서 설치할 수 있게 된 뒤 사용하는 게시글 초안입니다. 게시하거나 예약하지 않았습니다.

## 추천 게시 방법

첫 게시글에는 `post-ko.txt`를 붙이고 이미지 `01-launch.png`, `02-before-after.png`를 순서대로 첨부합니다. 반응형 동작도 강조하려면 `03-responsive.png`를 세 번째 이미지로 첨부합니다. 세 이미지 모두 1600×1000 PNG입니다.

`{{STORE_URL}}`은 공개된 Chrome 웹 스토어의 실제 설치 링크로 바꿉니다. 개발자 대시보드 링크를 사용하지 않습니다. 로그인하지 않은 창에서도 설치 페이지가 열리는지 확인한 뒤 게시합니다. 이미지에는 버튼처럼 보이는 설치 링크나 QR 코드를 넣지 않아 링크 수정 없이 사용할 수 있습니다.

`reply-ko.txt`는 사용 방법과 개인정보 처리 설명을 덧붙이는 답글입니다. 한국어 이미지 설명은 `alt-text-ko.txt`에 있습니다. `post-en.txt`와 `post-ja.txt`는 별도 언어 게시글용 번역이며, 이 자료의 이미지 문구는 한국어입니다.

## 소개하는 기능과 버전

저장된 제출 기록은 1.4.1 심사 제출, 개선 버전은 1.5.9 로컬 준비 상태입니다. 첫 출시용 문구·이미지는 1.4.1에서도 제공하는 북마크·마음에 들어요, 1~4열 반응형 그리드, 우측 사이드바 숨김, 직접 영상 재생에 맞췄습니다. 홈·검색·프로필의 그리드나 다국어 UI는 첫 출시 소개에 포함하지 않았습니다.

`post-update-ko.txt`는 개선 버전이 실제로 공개된 뒤 사용하는 별도 업데이트 소개입니다. 첫 1.4.1 승인 게시글과 섞지 않습니다.

브랜드 이미지는 사용자가 선택한 새 X 그리드 아이콘입니다. 현재 제출된 1.4.1 패키지에는 이전 아이콘이 들어 있으므로 첫 공개본의 스토어 아이콘과 다를 수 있습니다. 스토어 등록정보나 심사 제출은 변경하지 않았습니다.

## 화면 출처

개인 계정이나 저장된 게시물을 촬영하지 않았습니다. `demo.html`의 창작 샘플 게시물에 현재 저장소의 실제 확장 CSS/JS(1.5.9)를 적용하고 브라우저로 촬영했습니다. 기본 보기와 그리드 비교는 같은 게시물을 사용합니다. 각 이미지에 데모 표기를 넣었습니다. 4열·2열·1열은 실제 렌더링 결과로 확인했습니다.

`grid.png`, `native.png`, `two-columns.png`, `one-column.png`는 합성 전 원본 화면 캡처입니다. `index.html`은 세 가지 소개 이미지의 편집 가능한 HTML 원본입니다. 사진이나 실제 X 화면으로 오인하게 설명하지 않습니다.

## 재생성

저장소 루트에서 `node marketing/x-launch/preview.cjs`를 실행합니다.

- 그리드: `http://127.0.0.1:4174/i/history/likes?width=1320`
- 기본 목록: `http://127.0.0.1:4174/i/history/likes?mode=native&width=990`
- 2열: `http://127.0.0.1:4174/i/history/likes?width=788`
- 1열: `http://127.0.0.1:4174/i/history/likes?width=488`
- 소개 이미지: `http://127.0.0.1:4174/marketing/x-launch/index.html?slide=hero`
- 비교 이미지: 위 URL의 `slide=comparison`
- 반응형 이미지: 위 URL의 `slide=responsive`

브라우저의 실제 너비를 각 데모 너비에 맞춰 촬영합니다. 소개용 HTML의 출력 크기는 1600×1000입니다.

게시글 길이는 URL을 23자로 계산하고 한글·일본어의 가중치를 반영해 확인했습니다. [X 공식 문자 수 안내](https://docs.x.com/fundamentals/counting-characters)를 참고했습니다. 문구를 추가하면 게시창에서 다시 확인합니다.
